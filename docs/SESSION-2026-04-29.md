## Decisioni architetturali

1. Helper `isRichDataSource` in `packages/shared` (non duplicato in
   `apps/api` e `apps/web`)
2. ON CONFLICT DO NOTHING + SELECT post-conflict per upsert (atomicita
   senza transaction esplicita)
3. Dynamic import in script CLI per caricare `.env` prima dei moduli
   BullMQ
4. Logger pino diretto nei worker (non `app.log` Fastify, decoupling
   lifecycle)
5. `maxRetriesPerRequest: null` su ioredis connection (richiesto da
   BullMQ Worker)
6. Trigger workflow fire-and-forget post-update endpoint (response
   veloce, errori loggati)
7. `airbnb_ical_only` valore `data_source` (INCOMPLETE ma non triggera
   UI form M2a.4)

## Edge case scoperti

- `skip-completion`: Fastify rifiuta body vuoto con
  `Content-Type=application/json` (vedi KNOWN-LIMITS §17)
- Fly Free tier: machine auto-stop dopo inattivita (vedi KNOWN-LIMITS
  §18)
- Fly Redis non raggiungibile dal Mac locale, solo da app Fly internal
- Token iCal Booking si rigenera se ruoti calendar (URL vecchio diventa
  invalido)
