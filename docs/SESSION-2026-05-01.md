## Gotcha del giorno: Supabase rate limit SMTP default

Supabase rate-limita le email magic link a ~4 per ora sul default SMTP gratuito (`noreply@mail.app.supabase.io`). Sufficiente per il pilot ma fragile durante sessioni di test multipli.

Mitigazione attuale: aspettare il reset dell'ora.

Risolutione: SMTP custom via Resend (o simile) gia' tracciato in `KNOWN-LIMITS.md` §22 come slice 6.5 dedicato a email branding.
